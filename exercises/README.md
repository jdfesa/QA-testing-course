# Exercises

This directory contains hands-on course practice grouped by testing area:

- `manual-testing/`: manual test analysis, design, and execution.
- `web-testing/`: functional and exploratory testing of web applications.
- `api-testing/`: API requests, responses, collections, and validations.
- `automation/`: test automation exercises and source code.

When appropriate, each exercise should document its objective, execution steps, result, and conclusions.
