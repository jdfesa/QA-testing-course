# Assets

This directory stores evidence and supporting files used by notes, exercises, and projects:

- `screenshots/`: captures of results, defects, quizzes, or test executions.
- `diagrams/`: diagrams and visual explanations.
- `files/`: other supporting files that do not fit the previous categories.

## Asset Naming

- Use English `kebab-case` names.
- Start class-specific assets with `class-NN-`.
- Add the activity and a short descriptor, for example `class-02-quiz-result.png`.
- Use `diagram-` after the class prefix for diagrams, for example `class-04-diagram-testing-levels.png`.
- Add a date only when multiple chronological captures need to be distinguished.

Keep assets in these shared folders and use the class prefix for context. This avoids creating a deep directory tree for a small course repository.
