# Notes

This directory contains personal theory and study notes from the course.

## Organization

- `classes/`: notes arranged according to the numbered classes in the virtual course.
- `summaries/`: short review material across one or more classes.
- `glossary.md`: important QA terms and concepts.

Create each class folder only when there is real content to add. Use the format `class-NN-short-topic` and start from [`../templates/note-template.md`](../templates/note-template.md).
