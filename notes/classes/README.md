# Classes

Course notes are organized here using the same numbered sequence as the virtual classroom.

Use one directory per class and keep only the files that are genuinely useful:

```text
class-02-software-development-and-qa/
├── notes.md
├── summary.md
└── questions.md
```

Do not create all 16 class directories in advance. A directory should appear when its first note, exercise reference, or supporting resource is added.
